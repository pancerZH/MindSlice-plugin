Commands use the plugin's `mindslice` CLI, which is not on the shell's `PATH`: call it by the absolute path the standing memory pages give (typically `~/.codex/plugins/data/mindslice-mindslice/bin/mindslice`). It targets the plugin's workspace unless you pass `-w <workspace>` or run it inside another MindSlice workspace. Codex's sandbox keeps shell commands from writing outside the project, so run the commands that use the workspace with escalated permissions (the user approves them).
