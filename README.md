# MindSlice-plugin

Packages MindSlice long-term memory as ready-to-install plugins for AI agent harnesses.

Engine: [MindSlice](https://github.com/pancerZH/MindSlice) (installed from PyPI as `mindslice`).

## Supported plugins

- **Claude Code**: Linux, macOS, Windows (with Git for Windows) ([plugins/claude](plugins/claude/README.md))
- **Antigravity**: tested with the `agy` CLI (Linux, Windows) and the Antigravity app (Windows); macOS is not verified yet ([plugins/antigravity](plugins/antigravity/README.md))
- **Codex**: tested with the Codex CLI on Linux; macOS and Windows are not verified yet ([plugins/codex](plugins/codex/README.md))
- **DeepSeek Harness**: Cordis bundle (`dsh-mindslice`) for Desktop, Web and CLI; verified with Node/Python unit and integration tests on Linux, pending live Windows Desktop verification ([plugins/deepseek-harness](plugins/deepseek-harness/README.md))
